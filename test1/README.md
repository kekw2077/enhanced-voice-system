# Nexus Anima — Flutter-приложение

Десктопный голосовой ассистент для Windows. Описание продукта и возможностей — в
[README проекта](../README.md), карта кода и правила работы — в [CLAUDE.md](CLAUDE.md).

Это папка самого приложения: Flutter-часть (`lib/`), голосовой движок на Python
(`sidecar/`), серверы для домашней станции (`server/`), сборка и выпуск (`dist/`).

## Быстрый старт

```powershell
flutter pub get
flutter run -d windows        # приложение
flutter analyze               # линт и типы
flutter test                  # тесты (13 файлов в test/)
```

Голосовой движок в разработке запускается из исходников (`python sidecar/main.py`),
в собранном приложении — как отдельный компонент `anima_sidecar.exe`, который
догружается при первом включении голоса.

## Платформа

Только **Windows**. Папки `android/`, `ios/`, `macos/`, `linux/`, `web/` остались от
общего с мобильной версией прошлого и здесь не поддерживаются — мобильная линия живёт
в своём репозитории.
