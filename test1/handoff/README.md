# EVS — перенос интерфейса в код

Всё, что нужно, чтобы собрать этот интерфейс на Flutter/Dart и открыть папку в VS Code.

## С чего начать

1. Откройте `design/EVS Interface.dc.html` в браузере — держите рядом при работе.
   Это точный эталон: цвета, отступы, тексты, поведение.
2. Скопируйте `flutter/lib` и `flutter/shaders` в свой проект.
3. Допишите в `pubspec.yaml` строки из `flutter/pubspec.snippet.yaml`.
4. Запустите `lib/main_example.dart` — увидите оболочку с фоном и сеткой точек.
5. Дальше экраны переносятся по одному. Порядок и разбор — в `GUIDE.md`.

## Что уже готово в Dart

Оболочка, оба фона, сетка точек в обоих режимах, стеклянные панели, вся палитра
с четырьмя акцентами и двумя темами, переключение оформления на лету.

**Все восемь экранов перенесены:**

| Файл | Экран |
|---|---|
| `welcome_screen.dart` | Экран приветствия + галочка «не показывать при запуске» |
| `hub_screen.dart` | Центр: шар ассистента, метрики, чат |
| `chat_screen.dart` | Диалог: лента, список чатов, поле ввода |
| `commands_screen.dart` | Команды: каталог фраз, медиа-шорткаты |
| `modules_screen.dart` | Модули: карточки подсистем, график, журнал |
| `images_screen.dart` | Nexus Lumina: параметры, холст, история |
| `voice_screen.dart` | Nexus Sonora: голос, текст, волна, история |
| `settings_screen.dart` | Настройки: 11 разделов, все строки и типы полей |

Данные из прототипа лежат в `lib/data/` — тексты, списки и значения по
умолчанию перенесены дословно, чтобы экраны выглядели точно так же.

**Плюс к экранам готово:**

- **Плавающий виджет** (`floating_widget.dart`) — визуализация в маленьком
  прозрачном окне поверх остальных. Подложка и подпись состояния появляются
  под курсором, двойной клик возвращает в чат, перетаскивание двигает окно.
  Окно создаётся в `main_widget.dart` (`flutter run -t lib/main_widget.dart`).
- **Семь стилей визуализации** (`viz_visual.dart`): Сфера, Волны, Бары,
  Siri Orb, Полоски, Волны 3D, Поле частиц. Работают и в виджете, и в
  предпросмотре настроек.
- **Меню чатов** на экране «Диалог»: закрепить, переименовать, очистить,
  удалить — со списком, который живёт по-настоящему.
- **Анимации** (`anim_accent.dart`): breathe (поворот оттенка у фона), flow
  (текучий градиент у заголовков), pulse. Режим берётся из настроек; при
  «Экономии» контроллеры не создаются вовсе.
- **Хранение настроек** (`evs_prefs.dart`) — тема, акцент, стекло, фон, сетка,
  все строки настроек и галочка приветствия переживают перезапуск.

## Что делать дальше

Заменить демонстрационные данные на настоящие: метрики железа, ответы модели,
каталог команд. Все места собраны в `lib/data/` и в полях состояния экранов
(`_cpu`, `_messages`).

Из системного осталось подключить трей, автозапуск и глобальную горячую
клавишу — пакеты названы в `pubspec.snippet.yaml`, а сама работа с
микрофоном, моделью и синтезом лежит вне интерфейса.
