# Распознавание речи на своём сервере

Разворачивает контейнер, к которому EVS подключается как к «движку на сервере»
(«Микрофон и распознавание» → «Распознавание» → «На сервере»).

```bash
scp deploy-stt.sh user@сервер:~
ssh user@сервер 'bash ~/deploy-stt.sh'
```

Скрипт сам выберет CPU- или CUDA-образ, поднимет контейнер, дождётся готовности
и проверит **тот самый** эндпоинт, которым пользуется EVS. В конце напечатает
адрес, который нужно вставить в настройки.

Повторный запуск обновляет образ. `--down` останавливает, `--logs` показывает
логи, `--port N` меняет порт.

## Что именно разворачивается и почему

[gigastt](https://github.com/ekhodzitsky/gigastt) — сервер поверх **GigaAM-v3**
(Сбер), с OpenAI-совместимым `POST /v1/audio/transcriptions`. Лицензия MIT,
готовые образы `ghcr.io/ekhodzitsky/gigastt:latest` и `:cuda`.

Почему не Whisper: на русском GigaAM одновременно точнее и дешевле — по замерам
автора ~3.5% WER на чистой записи против ~5–9% у Whisper large-v3, при этом
модель 225 МБ (INT8) и работает примерно **в 10 раз быстрее реального времени на
процессоре**. То есть видеокарта для распознавания не обязательна; когда она
появится в сервере, скрипт сам переключится на CUDA-образ.

**Ollama здесь не при чём** — она умеет только языковые модели, распознавания
речи в ней нет. Нужен именно этот отдельный контейнер; с Ollama они спокойно
живут на одной машине.

## Если понадобится не русский

GigaAM — русскоязычная модель. Для многоязычного распознавания вместо неё
поднимается [speaches](https://speaches.ai/) (Whisper под тем же OpenAI-
совместимым контрактом, так что настройки EVS не меняются):

```bash
docker run -d --name evs-stt-multi --restart unless-stopped \
  -p 9877:8000 -v hf-hub-cache:/home/ubuntu/.cache/huggingface/hub \
  ghcr.io/speaches-ai/speaches:latest-cuda      # без видеокарты: latest-cpu
```

На процессоре Whisper large-v3 заметно медленнее реального времени — с ним
видеокарта уже действительно нужна.

## Безопасность

Порт открыт без авторизации: контейнер рассчитан на доверенную локальную сеть.
Наружу его выставлять нельзя. Если нужен доступ извне — заворачивайте в reverse
proxy с TLS и Basic/Bearer-авторизацией, ключ вводится в EVS в поле «Ключ
доступа».

## Что осталось проверить вживую

Скрипт написан и разобран по шагам, но на этой машине нет Docker — контейнер
здесь не запускался. Со стороны EVS проверено всё остальное: формат запроса
(против настоящего HTTP-сервера), разбор ответа, фолбэк на локальный движок и
весь путь приложение → сайдкар → сервер.
