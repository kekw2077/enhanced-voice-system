# Клон голоса на видеокарте (Qwen3-TTS) — установка

Заменяет вырезанный CPU-клон (XTTS), который давал невнятную озвучку.
Модель — **Qwen3-TTS** (Apache-2.0, русский, клонирование по образцу), работает
на твоей RTX 3060.

Сервер запускается **в твоём venv**, а не внутри EVS: тяжёлый CUDA+torch (~5 ГБ)
не тащится в установщик и не ломает автообновление.

> **CosyVoice никуда не делся.** Движок «Клон (сервер)» говорит по одному и тому
> же протоколу (`POST /inference_zero_shot`), поэтому в поле адреса можно указать
> либо локальный Qwen3-TTS (ниже), либо CosyVoice-сервер — например, когда на
> домашнем сервере появится видеокарта и весь рендер переедет туда. Менять в EVS
> ничего не придётся, только адрес. Настройки «Нагрузка на видеокарту» относятся
> к локальному серверу Qwen3-TTS; удалённый CosyVoice считает на своей машине и
> эти параметры игнорирует.

---

## 1. Установка (один раз)

```powershell
# в папке проекта, в своём venv
pip install -U qwen-tts soundfile numpy
# torch с CUDA (для RTX 3060 подходит cu124):
pip install torch --index-url https://download.pytorch.org/whl/cu124
```

Проверка, что видеокарта видна:

```powershell
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# ожидается: True NVIDIA GeForce RTX 3060
```

## 2. Запуск сервера

```powershell
python qwen_tts_server.py --port 8760
```

Первый запуск скачает веса модели (~4 ГБ). **Всё пишется на диск, где стоит
EVS** — по умолчанию в `F:\EVS\userdata\components\hf-cache` (тот же кэш, что у
Whisper). Ничего не уходит на `C:\Users\...`. Переопределить:
`--cache-dir "F:\путь"` или переменной `EVS_QWEN_CACHE`.

Полезные флаги (обычно не нужны — всё настраивается из EVS):

| Флаг | Смысл |
|---|---|
| `--model` | другая модель (по умолчанию `Qwen/Qwen3-TTS-12Hz-1.7B-Base`; есть 0.6B — легче) |
| `--preload` | загрузить модель сразу, а не при первой фразе |
| `--vram-fraction 0.4` | жёсткий потолок видеопамяти |
| `--idle-unload 120` | выгружать из VRAM после N секунд простоя (0 — никогда) |
| `--throttle 0.3` | пауза после каждой фразы (0..1) — ниже средняя нагрузка |

## 3. Настройка в EVS

**Настройки → Голос → Движок озвучки:**

1. Адрес клон-сервера: `http://127.0.0.1:8760` → **Проверить соединение**
   (должно стать «На связи»).
2. Выбрать движок **«Клон (GPU)»**.
3. Указать **образец голоса** (WAV, 6–10 секунд чистой речи) и текст, который в
   нём произнесён (это заметно улучшает схожесть).

## 4. Нагрузка на видеокарту

Ползунка «занимать N% GPU» на уровне драйвера не существует, поэтому нагрузка
регулируется четырьмя реальными рычагами (**Настройки → Голос → Нагрузка на
видеокарту**):

| Профиль | Лимит VRAM | Выгрузка в простое | Сдерживание |
|---|---|---|---|
| **Максимум** | без лимита | 10 мин | нет |
| **Баланс** (по умолчанию) | 5 ГБ | 2 мин | 25% |
| **Тихий** | 3 ГБ | 30 сек | 60% |

Отдельно — **«Когда запущена игра»** (использует игровой режим EVS: полный экран
или высокая занятость видеопамяти):

- **Кэш + Piper** (по умолчанию) — знакомые фразы играют из кэша (видеокарта не
  трогается вообще), новые озвучиваются обычным голосом. Модель выгружается из
  VRAM.
- **Как обычно** — синтез на GPU продолжается (может стоить FPS).
- **Выключать** — только Piper.

После выхода из игры EVS сам возвращает клон-движок.

> Совет: заранее прогони предзаготовку фраз (она запускается автоматически при
> активации клона) — тогда в игре почти всё будет играть из кэша без GPU.

## 5. Автозапуск (по желанию)

Чтобы не запускать сервер руками, сделай ярлык в автозагрузке:

```powershell
# ярлык на:  pythonw.exe  F:\путь\qwen_tts_server.py --port 8760
```

`pythonw` — без окна консоли. EVS сам достучится, когда сервер поднимется; пока
его нет, озвучка идёт обычным Piper.
