# Токены и темы Nexus Anima

Рядом лежит `app_tokens.dart` — рабочий шаблон, а не псевдокод. Значения темы Prism перенесены из твоего HTML-макета один в один, имена токенов оставлены твои же (`card`, `field`, `chip`, `stroke`, `a1`–`a3`, `dot`), чтобы не пришлось переучиваться.

## Куда класть

```
lib/
  theme/
    app_tokens.dart      # класс токенов + все темы
    theme_controller.dart # переключение и сохранение выбора
```

Когда тем станет больше пяти, разнести по `lib/theme/themes/prism.dart` и так далее, а в `app_tokens.dart` оставить только класс и реестр.

## Почему ThemeExtension, а не свой InheritedWidget

`ThemeExtension` умеет `lerp`, поэтому Flutter анимирует переключение темы сам: цвета переливаются, а не прыгают. Со своим InheritedWidget это пришлось бы писать руками. Плюс токены доезжают до любого виджета через обычный `Theme.of(context)`, включая чужие пакеты.

В виджете:

```dart
final t = Theme.of(context).extension<AppTokens>()!;

Container(
  decoration: BoxDecoration(
    color: t.card,
    border: Border.all(color: t.stroke),
    borderRadius: BorderRadius.circular(14),
  ),
  child: Text('Привет', style: TextStyle(color: t.txt)),
);
```

## Как добавить новую тему

1. Скопировать `prismDark`, поменять имя и цвета.
2. Добавить строку в `appThemes`.

Всё. Больше ничего трогать не нужно — ни виджеты, ни настройки.

Одно правило при подборе: у токена есть роль, а не цвет. `stroke` — это «граница», а не «серый». Если в новой теме граница станет светящейся голубой, она всё равно остаётся `stroke`. Как только начинаешь заводить токены вида `blueBorder`, система рассыпается.

## Два токена, которых не было в HTML

**`backdrop`** — как рисуется фон окна. Значение `systemMica` или `systemAcrylic` означает, что размытие делает композитор Windows, а приложение не тратит на это ни кадра. `painted` оставлен для тем, которым нужен именно собственный градиент, но тогда фоновые пятна надо запекать в картинку, а не размывать вживую.

При `backdrop != opaque` фон Scaffold обязан быть прозрачным, иначе системный материал будет закрашен сверху и эффекта не будет. В `buildTheme` это уже учтено.

**`motion.scale`** — множитель активности анимаций: 1.0 в фокусе, 0.5 когда окно видно но не активно, 0.0 когда свёрнуто. Важный нюанс: при нуле ambient-анимации должны не замедляться, а останавливать свой `Ticker`. Замедленная анимация рисуется точно так же, просто реже меняется, и GPU это не экономит.

Ставить `scale` там же, где ловится фокус окна:

```dart
// при потере фокуса
setTokens(tokens.copyWithMotion(tokens.motion.withScale(0.5)));
```

## Что прислать мне, чтобы виджеты вставлялись без правок

Один раз, дальше буду держать в контексте:

1. Итоговый `app_tokens.dart` после твоих правок — по нему я пишу `t.card`, а не `Color(0xFF...)`.
2. Любой готовый экран целиком — с него я снимаю твои соглашения: как называешь файлы, как разносишь виджеты, что используешь для состояния.
3. Версию Flutter и на чём построен UI — Material 3 или свои компоненты.

Что буду отдавать: `StatelessWidget` без `Scaffold` и без `MaterialApp`, все размеры и цвета через токены, параметры вместо захардкоженных строк. Такой виджет вставляется в любое место дерева и не тянет за собой обвязку.

## Проверка темы перед тем, как считать её готовой

- Контраст `body` на `card` — не ниже 4.5:1, `sub` на `bg` — не ниже 3:1.
- `stroke` виден на `card`, но не спорит с `txt`.
- `danger`, `ok`, `warn` различимы при цветовой слепоте — не полагаться только на оттенок, дублировать иконкой.
- Светлая тема проверяется на белом фоне монитора при яркости 100%, а не в тёмной комнате: половина неудачных светлых тем рождается вечером.
