# ТЗ — Стиль интерфейса «Ноктюрн» (третий UI-стиль EVS)

Версия 1.0 · 27.07.2026
Референс-макеты: `EVS Ноктюрн.dc.html` (экраны `1a`–`1j`).
Репозиторий: `kekw2077/enhanced-voice-system`, приложение в `test1/`.
Опирается на ТЗ `tz-ui-style-nexus.md` — вся инфраструктура стилей уже описана и внедрена там, здесь только третье значение оси.

---

## 1. Цель

Добавить третье значение оси «Стиль интерфейса»: **Классический · Nexus · Ноктюрн**.

«Ноктюрн» отличается от Nexus не палитрой, а **компоновкой окна**. Nexus — пульт: рейл, орб со спутниками, четыре карточки подсистем, чат постоянной колонкой. «Ноктюрн» — инструмент: вкладки сверху, сцена во всё окно, чат отдельным экраном, телеметрия одной моноширинной строкой по низу.

Классический стиль и Nexus после внедрения не меняются ни на пиксель.

## 2. Модель

Ось стиля уже есть: `enum AppStyle { standard, nexus }` → добавляется `noctur`. `EvsSkin` / `skinFor(AppStyle, AppThemeMode)` из ТЗ Nexus расширяется третьей веткой. Тема по-прежнему задаёт только палитру.

Матрица: 3 стиля × темы. Для «Ноктюрна» обязательны **тёмная** и **светлая** палитры (§4); Claude-темы отображаются на них по правилу §4.3.

## 3. Изменения по файлам

### 3.1 `lib/src/models.dart`
`enum AppStyle { standard, nexus, noctur }`. Фолбэк `orElse: () => AppStyle.standard` уже есть — старый билд тихо откатится.

### 3.2 `lib/src/app_state.dart`
Изменений нет: `setAppStyle` уже добавлен в ТЗ Nexus.

### 3.3 `lib/src/theme_widgets.dart`
`EvsSkin` дополняется полями, которых требует «Ноктюрн»:

```dart
class EvsSkin {

  final double topBarHeight;   // 52 (noctur) / 0
  final double statusBarHeight;// 34 (noctur) / 0
  final bool   tabsNav;        // true → вкладки вместо рейла
  final bool   glow;           // true только на тёмной палитре

}
```

`railWidth = 0` для «Ноктюрна».

### 3.4 Новые виджеты
- `NocturTopBar` — шапка 52 px (§5.1).
- `NocturStatusStrip` — строка телеметрии 34 px (§5.4).
- `NocturRingViz` — визуализатор-кольцо (§6). Заменяет `NexusStageViz` только внутри этого стиля.

## 4. Токены

### 4.1 Тёмная (референс)

| Токен | Значение |
|---|---|
| bg | `#161826` (плоский, без радиальных пятен — в отличие от Nexus) |
| surface | `bg + 4 % text` |
| line / line2 | `text @ 9 %` / `text @ 17 %` |
| text / dim / faint | `#e9e9ed` / `#9397ab` / `#75798c` |
| accent | `#9184d9` |
| warn · «слушаю» | `#c9a15f` |
| info · «говорю» | `#6fb3c9` |
| success | `#7bb489` |
| danger | `#cc7f7f` |

Все семантические слоты низкохроматичны и лежат на одной перцептивной светлоте с акцентом — цвет различает роль, а не кричит.

### 4.2 Светлая

bg `#f1f1f6` · surface `#fbfbfe` · text `#292b31` · dim `#595d6c` · faint `#75798c` · accent `#6f61c0` · warn `#8a6a2a` · info `#35707f` · success `#3f7a53` · danger `#a04a4a` · line `text @ 11 %` / line2 `text @ 20 %`.
`glow = false`: свечения точек и кольца заменяются мягкой тенью `0 22px 60px rgba(41,43,49,.10)`.

### 4.3 Claude-темы в «Ноктюрне»
Геометрия «Ноктюрна» + существующие палитры Claude / Claude-тёмная, слоты один-в-один по ролям (accent → `#CC785C` / `#D97757`). Отдельных значений не вводим.

### 4.4 Геометрия

Радиусы: окно 14 · карточка 10 · контрол 8–10 · пилюля 999.
Высоты: шапка 52 · строка телеметрии 34 · поле ввода 42 · навигация настроек 252.
Поля экрана 40 (узкое окно — 26). Плотность 0.70×, как в дизайн-системе.

### 4.5 Типографика

Inter. Заголовок экрана 21/500/-0.01em · заголовок карточки 13.5/500 · строка 13/400 · описание 11.5/400 faint · телеметрия и служебные метки — моноширинный 11 · кикер mono 10.5 uppercase letter-spacing .2em.

### 4.6 Линии
Свободные горизонтальные линейки гаснут в прозрачность по 48 px с каждого конца (`linear-gradient(90deg, transparent, line 48px, line calc(100% - 48px), transparent)`). Границы карточек, разделители внутри контролов и короткие акцентные штрихи — сплошные.

## 5. Экраны

### 5.1 Шапка (общая, `NocturTopBar`) — макет `1a`
Слева направо: марка 22 px (контур accent + точка 6 px) · «EVS» 12/500/.16em · разделитель · четыре текстовые вкладки **Диалог · Команды · Модели · Журнал** (активная — цвет text и сплошной штрих accent 2 px под текстом) · распорка · пилюля состояния (точка нужного слота + подпись) · иконка настроек · разделитель · кнопки окна.

Вкладки открывают экраны, а не разделы настроек. Иконка шестерёнки открывает настройки поверх (макет `1f`).

### 5.2 Главный экран — макет `1a`
Сверху вниз:
1. **Строка состояния** (flush-left): кикер «СОСТОЯНИЕ», точка + название состояния 21/500, подсказка 12.5 faint. Справа — слово-активатор (из `cmdActivator`, не хардкод) и глобальный хоткей в контурных капсулах.
2. **Кольцо** `NocturRingViz` 334 px по центру оставшейся площади.
3. **Цепочка конвейера**: `VAD — STT — LLM — TTS`, mono 10.5/.16em, точки 5 px; соединители — гаснущие линейки 56 px. Активный этап красится своим слотом, неактивные — faint.
4. **Транскрипт** flush-left, ширина ≤ 820: реплика пользователя 17/1.45 text, ответ 14.5/1.55 dim. Уважает `showPartial`.
5. **Поле ввода** 42 px: контурное поле «Спросите текстом — или просто скажите «Айрис»» + контурная кнопка микрофона accent 42×42.
6. **Строка телеметрии**.

Четыре карточки подсистем Nexus не переносятся: их содержимое живёт в телеметрии, детали — на вкладках «Модели» и «Журнал».

### 5.3 Соответствие состояний
| Состояние | Слот | Что горит в цепочке |
|---|---|---|
| Ожидание | faint | ничего |
| Слушаю | warn | VAD, STT |
| Думаю | accent | LLM |
| Говорю | info | TTS |

Слот красит: точку в пилюле шапки, точку и название состояния, кольцо (сектор-развёртка, внутренняя окружность, ядро, ореол), активные узлы цепочки и соответствующий сегмент телеметрии. Больше нигде.

### 5.4 Строка телеметрии (`NocturStatusStrip`) — 34 px, mono 11
Слева: `STT <движок> · <устройство>` · `LLM <модель> @ <хост>` · `TTS <голос> · <оффлайн|сервер>`. Справа: `GPU x.x / N ГБ` · `ответ ≈ n с`. Разделитель — «·» цветом line2. Активный этап красится слотом. При активной разгрузке GPU — `gmOffloadBadge` слотом warn. Источники данных — существующие (статус сайдкара, активная модель, метрики боковой панели).

### 5.5 Диалог — макет `1b`
Колонка диалогов 268 px: поиск, группы «Закреплено / Сегодня / Вчера», активный элемент — подложка accent @ 12 % + сплошной штрих accent 2 px слева; кнопка «Новый диалог» внизу (`btn-secondary`, во всю ширину).
Тред: заголовок диалога + мета mono (дата · модель · число реплик) + гаснущая линейка; реплика пользователя — контурный пузырь accent @ 12 %, ответ — плоский текст с мета-строкой mono (время · модель · длительность · «озвучено»); каретка потока — прямоугольник accent 7×15 с миганием 1 с. Композер: поле + микрофон + отправка (контурная accent).

### 5.6 Команды — макет `1c`
Заголовок + сводка («18 фраз · порог 0.72 · подтверждение для опасных»), справа `Предложить команды` (ghost) и `Добавить команду` (primary). Поиск + теги-фильтры по типам. Таблица `.table`: Фраза-триггер · Действие (mono 12 dim) · Тип (tag neutral) · Отклик · меню строки. Опасные команды помечаются контурным тегом danger «подтверждение». Внизу закреплены два глобальных правила: порог совпадения (слайдер + значение mono) и подтверждение (сегмент-контрол).

### 5.7 Модели — макет `1d`
Верх: сегмент «Локально / Удалённый сервер». Две карточки: активная модель (имя, mono-строка «сервер · контекст · размер», статус подключения точкой success) и адрес сервера (поле + `Проверить`). Ниже — каталог: сегмент тиров (Лёгкие · Средние · Мощные · Ролевые), сетка карточек 3 в ряд: имя, mono `квантование · размер · формат`, описание, статус (`tag-accent` «установлена» / `tag-outline` с процентом / без тега), полоса загрузки 3 px accent, действия контурными кнопками. Подвал — mono сводка по диску и VRAM.

### 5.8 Журнал — макет `1e`
Фильтры тегами (Все · Голос · Модель · Команды · Обновления · Ошибки с счётчиком) + поиск. Поток mono 12/1.9 внутри поверхности с рамкой: время faint 58 px · **вертикальный штрих 3 px цветом уровня** · источник faint 78 px · сообщение dim. Строки ошибок целиком красятся danger. Уровень: success — норма, warn — голосовой тракт, accent — модель/метрики, danger — ошибка. Действия — «Скопировать» и «Папка логов».

### 5.9 Настройки — макет `1f`
**Структура не меняется**: те же 10 групп и те же страницы (`_kNav`, `_Pages`). Меняется только скин:
- Шапка настроек: кнопка «Назад» контурная + заголовок; вкладок нет.
- Навигация 252 px: строка группы = иконка 16 + название 13 + подпись 11 faint; активная группа — подложка accent @ 12 %, её страницы раскрыты списком с отступом 38 и сплошным штрихом accent у активной. Версия — mono внизу.
- Контент: заголовок страницы 21/500, подзаголовок, гаснущая линейка, далее карточки в две колонки. Шапка карточки — иконка accent + название + сплошной разделитель.
- Контролы: сегмент-контрол, тумблер 36×20 (контур accent + заливка accent @ 22 % во включённом), слайдер 3 px, поля-капсулы mono для хоткеев.
- **Dirty-бар не отображается**, как и в Nexus; единственная точка подтверждения — существующий диалог при выходе.

### 5.10 «Стиль интерфейса» — три плитки
Карточка «Внешний вид», первая строка. Три превью ~120×72 (`CustomPainter`, без новых ассетов): Классический (рейл + одна колонка), Nexus (узкий рейл + круг + колонка чата), Ноктюрн (полоса шапки + кольцо-контур + полоса телеметрии). Выбранная — рамка accent + внешний контур accent @ 40 %. Клик → `setAppStyle` → кроссфейд ≤ 200 мс, вне dirty-механизма.

Новые ключи i18n (RU+EN): `uiStyleNoctur` «Ноктюрн», `uiStyleNocturDesc` «Вкладки, сцена во всё окно, строка телеметрии».

### 5.11 «Что нового» — макет `1g`
Диалог 640 px: кикер mono, «Что нового» 26/500 + версия в контурной капсуле accent, гаснущая линейка, список пунктов — вертикальный штрих 3 px (accent / success / info) + заголовок 14 + описание 12.5 dim. Подвал: ссылка «Полный список изменений» слева, `Позже` (ghost) и `Понятно` (primary) справа.

## 6. `NocturRingViz`

CustomPainter + Ticker. Вход: `state`, `level` (0..1), `EvsSkin`. Один режим — кольцо (переключателя режимов у стиля нет; три сцены Nexus остаются у Nexus).

Слои от внешнего к центру, для габарита 334 px:
1. Ореол: радиальный градиент слотом @ 16 %, вылет 46 px, дыхание 5.6 с (в светлой теме — тень вместо градиента).
2. Внешняя окружность 1 px line.
3. **Кольцо штрихов**: 100 радиальных штрихов (шаг 3.6°, толщина 0.45°) цветом text @ 26 %, кольцевая маска 63–100 % радиуса, вращение 140 с.
4. **Сектор-развёртка**: конический градиент от прозрачного к слоту, вращение 7 с (в «думаю» — 4 с), режим смешивания screen.
5. Пунктирная окружность text @ 12 %, вращение против часовой 90 с.
6. Внутренняя окружность 1 px слотом @ 45 %, дыхание 4.2 с.
7. Ядро 9 px слотом со свечением 22 px.
8. **Уровень**: 5 столбиков 2 px под кольцом, высота от `level`, видны в «слушаю» и «говорю».

Производительность — через существующий `MotionPolicy`: `full` 60 fps; `balanced` 60 fps при state ≠ idle, ~24 fps в простое; `saver` — статичный кадр (все вращения остановлены, кольцо и ядро отрисованы один раз). Рендер на паузе при скрытом/свёрнутом окне.

## 7. Адаптив — макет `1i`

Порядок сжатия при уменьшении окна:
1. Телеметрия теряет хвосты: адрес хоста → имя модели → только названия движков.
2. Подсказка активации сворачивается в одну строку, затем скрывается.
3. Кольцо уменьшается: 334 → 268 → 212 px.
4. Строка состояния и пилюля в шапке сливаются: в шапке остаётся точка, название переезжает в сцену.
5. Ниже 860 px — вкладки становятся иконками с подсказками.
Минимальный габарит окна — 860×560. Высоты шапки и телеметрии не меняются никогда.

## 8. Этапы

1. **Инфраструктура.** `AppStyle.noctur`, ветка в `skinFor`, тёмная и светлая палитры, третья плитка в «Стиле интерфейса». На этом этапе «Ноктюрн» = скин поверх компоновки Nexus.
2. **Оболочка.** `NocturTopBar`, `NocturStatusStrip`, сцена с `NocturRingViz`, транскрипт, поле ввода; чат уходит из главного экрана на вкладку.
3. **Вкладки.** Диалог, Команды, Модели, Журнал в скине «Ноктюрна».
4. **Настройки и модалки.** Скин навигации/карточек/контролов, «Что нового».
5. **Полировка.** Claude-темы, кроссфейд, адаптив, перф-проход по `MotionPolicy`, регресс-скрины Классики и Nexus.

## 9. Критерии приёмки

- Классический стиль и Nexus после мержа визуально идентичны текущим (скрин-сравнение основных экранов).
- Тёмная и светлая палитры «Ноктюрна» читаемы; в светлой нет свечений, только тени.
- Ни один экран не использует цвет вне палитры скина; семантика состояний — только через слоты §5.3.
- Переключение стиля мгновенное, сохраняется между запусками, даунгрейд билда не падает.
- В настройках «Ноктюрна» нет всплывающего dirty-бара; диалог при выходе работает как раньше.
- CPU в простое при `balanced`/`saver` не выше Классики; при скрытом окне кольцо не рендерится.
- Все новые строки локализованы (RU + EN); слово-активатор и хоткей берутся из настроек.
- Окно 860×560 не ломает вёрстку ни на одной вкладке.

## 10. Вне объёма

Android-оболочка, плавающий виджет-оверлей, изменение состава и логики настроек, новые типы визуализаций, отключение dirty-бара в Классике.
